 
// The app to be developed is for managing a society called 'Vasundhra Palm Island' or VPI
// there are 3 Blocks - 'Mist', 'Breeze', and 'Dew'
// each block has around 100 flats (called 'Units')
// Management of the society involves - maintenance, upkeep, organising events, security, safety etc
// the society gets contributions (unitContributions) from each unit every month for managing the society
// There are individuals who own, reside, or both (when a owner is residing)
// unit residents may change with time
// owners may change with time
// To start with I am considering only 'management of contributions'.
// We will build: on-line payment (of contribution amount), publication of payment status at the end of first week every month
// other aspects such as maintenance (complaint management), security, safety, upkeep, and organising events will be considered later
// tables and relations are described as under
