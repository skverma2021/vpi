# Documentation Prompt Standards

Use these prompts when generating Markdown documentation for the vault.

---

## Feature Documentation Prompt
“Document the feature using the Feature-Template.md. Include: Summary, Actors, Preconditions, Flow, Exceptions, Acceptance Criteria.”

## Domain Rule Prompt
“Add domain rules for <topic> in Domain-Rules.md. Use clear, numbered statements.”

## Entity Documentation Prompt
“Document the <Entity> in Entities.md. Include attributes, relationships, and domain notes.”

## Workflow Documentation Prompt
“Document the workflow using the style in Development-Checklist.md and Release-Process.md.”

## Testing Documentation Prompt
“Document testing strategy for <feature> using Testing-Standards.md. Include unit, integration, and E2E coverage.”

## Design System Prompt
“Document UI standards using Design-System.md. Include Tailwind classes, button variants, table density, and form layout rules.”
