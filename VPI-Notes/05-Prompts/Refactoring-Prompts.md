# Refactoring Prompt Standards

Use these prompts when improving code structure, readability, or maintainability.

---

## Code Cleanup Prompt
“Refactor this code for clarity and maintainability. Do not change behavior. Follow naming conventions and design system rules.”

## Extract Component Prompt
“Extract reusable UI logic into a new component. Follow component naming conventions and place it in /components.”

## Extract Server Logic Prompt
“Move business logic into server actions. Keep UI components clean and declarative.”

## Improve Validation Prompt
“Refactor validation to use the Zod schema defined in /03-Implementation/Zod.”

## Improve Folder Structure Prompt
“Reorganize files to match the folder structure defined in the API Route Map and Naming-Conventions.md.”

## Performance Refactor Prompt
“Optimize this code for performance without changing behavior. Consider memoization, batching, and reducing re-renders.”

## Dead Code Removal Prompt
“Identify and remove unused imports, variables, and unreachable code.”
